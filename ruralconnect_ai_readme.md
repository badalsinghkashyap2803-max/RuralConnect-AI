# RuralConnect AI 🌾⚡

> **Tech4Bharat Hackathon | Problem Statement 8.2:** Rural Youth Employment & Skill-Matching Platform

**RuralConnect AI** is an AI-powered, accessible job matching and skill evaluation platform designed specifically for rural and semi-urban youth. By connecting job seekers directly with verified regional employers across Karnataka, RuralConnect AI eliminates middleman exploitation, flags suspicious job listings, and provides data-backed pathways to sustainable employment.

---

## 📌 Problem Statement Overview (PS 8.2)

Rural youth frequently face unemployment or underemployment due to:
* **Urban Bias in Job Portals:** Traditional job boards focus on corporate/software roles in tier-1 cities.
* **Lack of Trust & Fraud:** High incidence of fake job offers requiring upfront payments.
* **Information Asymmetry:** Limited access to local trade job listings (micro-enterprises, solar units, ag-machinery service hubs).
* **Skill Mismatch:** Difficulty translating vocational skills (electrical, plumbing, tailoring, agri-tech) into verified job applications.

**RuralConnect AI** solves these challenges with a decentralized, trade-focused, trust-verified job matching engine tailored for regional district clusters.

---

## 🌟 Key Features

### 1. 🤖 AI-Powered Skill & Role Matching
* Calculates compatibility scores ($0-100\%$) based on practical skills, location proximity, experience, and salary expectations.
* Suggests tailored skill-upgrading micro-courses when a candidate meets partial requirements for a role.

### 2. 🛡️ Employer Verification & Fraud Prevention Badges
* Evaluates job listings using safety heuristics to protect job seekers.
* Displays distinct trust badges:
  * `Verified` — Authenticated local business / government-registered enterprise.
  * `Pending Review` — Newly submitted job listing undergoing check.
  * `Suspicious` — Flagged for high-risk indicators (e.g., asking candidate for registration fees).

### 3. 📊 District-Level Labor Market Analytics
* Interactive dashboard tracking monthly placement growth across key regional districts in Karnataka:
  * **Davanagere, Harihar, Shivamogga, Haveri, Chitradurga, Hubballi, Mysuru**
* Visualizes real-time demand trends across vocational sectors.

### 4. 🔧 Focus on Core Trade & Vocational Skills
Designed for real-world rural economies with dedicated categories for:
* Solar Panel Installation & Maintenance
* Electrical Wiring & Agricultural Pump Servicing
* Commercial Plumbing & Sanitation
* Apparel, Tailoring & Textile Manufacturing
* Ag-Machinery Repair & Equipment Servicing
* Data Entry, Billing & Local Retail Operations

### 5. 👥 Multi-Role Workflows & Multilingual UI
* **Job Seekers:** Build skill profiles, view AI match ratings, apply in one click, and access learning tracks.
* **Employers:** Post listings, review AI-ranked candidate lists, and verify trade credentials.
* **Admin / Government Panel:** Monitor platform analytics, review flagged listings, and track district placement metrics.
* Integrated language switcher for English and Kannada interface modes.

---

## 🛠️ Tech Stack & Architecture

* **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla ES6+)
* **Architecture:** Standalone single-file application (`ruralconnect-ai.html`) — zero external build dependencies, optimized for 2G/3G low-bandwidth connections.
* **Data & Analytics:** Client-side reactive state management & dynamic chart rendering.

## 🚀 Quick Start Guide

### Running Locally
No server setup or build toolchain required!

1. Clone the repository:
   ```bash
   git clone https://github.com/badalsinghkashyap2803-max/ruralconnect-ai.git
   ```
2. Navigate to the folder:
   ```bash
   cd ruralconnect-ai
   ```
3. Open `ruralconnect-ai.html` directly in any web browser (Chrome, Edge, Firefox, Safari).

## 🌐 Deploying to GitHub Pages

To publish RuralConnect AI as a live website:

1. Push your code to your main branch on GitHub.
2. Navigate to **Settings** > **Pages** in your repository (`badalsinghkashyap2803-max/ruralconnect-ai`).
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**.
5. Your live site will be published at:
   `https://badalsinghkashyap2803-max.github.io/ruralconnect-ai/ruralconnect-ai.html`
   *(Tip: Rename `ruralconnect-ai.html` to `index.html` to shorten the URL to `https://badalsinghkashyap2803-max.github.io/ruralconnect-ai/`)*
